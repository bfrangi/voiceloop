# voiceloop

A minimal web player for looping audio tracks — built for learning choral voice parts.

**[Open the app](https://bfrangi.github.io/voiceloop/)**

## How it works

1. Click **pick songs** and select a the audio files from your device.
2. Set how many times each track should repeat.
3. Hit **play** — the player works through every audio file in order, repeating each one the set number of times before moving to the next.
4. Use **prev** / **next** to jump between tracks at any time.

No upload, no server — everything runs locally in the browser.

## Use case

Load a folder of choir recordings split by voice part. Set the repeat count to whatever you need for the passage to sink in, and let it run.
